## Сборка CSS

После изменения файлов стилей пересоберите общий файл:

```sh
node scripts/bundle-css.js
```

Списки подключаемых стилей находятся в `pages/index.source.css` и
`pages/404.source.css`. Скрипт генерирует `pages/index.css` и `pages/404.css`,
а также встраивает стили главной страницы в `index.html`, чтобы первый экран
не ожидал отдельного CSS-запроса.
